# Animated DevFolio

A modern and responsive personal portfolio website built with HTML, CSS, JavaScript, jQuery, and Bootstrap. This enhanced version of DevFolio includes smooth animations, theme color customization, active navigation highlighting, and interactive UI elements to create an engaging user experience.

## Features

* Fully responsive design
* Smooth scrolling navigation
* Scroll-to-top button
* Theme color customization
* Animated page elements using WOW.js and Animate.css
* Active navigation link highlighting based on the current section
* Dynamic underline effect for the active navigation item
* Responsive navigation bar
* Portfolio showcase section
* About section
* Services section
* Contact section
* Improved user experience with interactive effects

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* jQuery
* Bootstrap
* WOW.js
* Animate.css
* Font Awesome

## How It Works

1. Users navigate through different sections of the portfolio.
2. WOW.js detects when elements enter the viewport.
3. Animate.css applies smooth entrance animations to page elements.
4. The active navigation link updates automatically while scrolling.
5. Users can switch between different color themes.
6. A scroll-to-top button appears when scrolling down the page.
7. Clicking the button smoothly returns the user to the top of the page.
8. The website remains fully responsive across desktop, tablet, and mobile devices.
